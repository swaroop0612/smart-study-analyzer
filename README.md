# 📚 Smart Study Analyzer

An intelligent personal study analytics platform that tracks your sessions, detects patterns, and gives personalized recommendations.

## Features
- 📊 6 Interactive Charts
- 🤖 AI Study Coach
- 🎯 Productivity Score
- 🧠 Study Personality Detection
- 🏆 Achievement System
- 🔥 Streak Tracking

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript, Chart.js
- **Backend:** Python, Flask
- **Database:** PostgreSQL (Neon)
- **Hosting:** Vercel + Render
